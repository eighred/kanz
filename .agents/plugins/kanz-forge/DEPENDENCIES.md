# Kanz Forge dependencies and engineering references

## Tools used at development time

| Tool | GitHub source | Use |
|---|---|---|
| Python | [python/cpython](https://github.com/python/cpython) | CLI, standard library, JSON, hashes and SQLite binding |
| SQLite | [sqlite/sqlite](https://github.com/sqlite/sqlite) | Embedded local evidence store through Python; upstream GitHub mirror |
| Git | [git/git](https://github.com/git/git) | Revision, file and worktree identity |
| GitHub CLI | [cli/cli](https://github.com/cli/cli) | Live metadata and review operations |
| Codex | [openai/codex](https://github.com/openai/codex) | Optional interactive agent workflows and plugin installation |
| Go | [golang/go](https://github.com/golang/go) | Kanz-owned financial tests |
| Node.js | [nodejs/node](https://github.com/nodejs/node) | Offline security-validator tests |
