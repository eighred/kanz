# Specs and plans

Dated records of work that was designed and executed. **They are history, not
instructions.**

Each file describes the tree as it stood on the date in its filename. Many
reference `KANZ_TASKS.md`, `KANZ_ROADMAP.md` or `tools/validate-board.sh` — all
deleted on 2026-07-28 when tracking moved to GitHub Issues. A step in one of
these plans that tells you to run `tools/validate-board.sh` or update the board
is describing what was true then, and will not work now.

Open work lives in GitHub Issues on `eighred/kanz`. Architectural decisions live
in `KANZ_BRAIN.md`. See `CLAUDE.md`.
