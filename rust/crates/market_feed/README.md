# Public market-feed library

`kanz-market-feed` is shared by the Binance and OKX Rust depth runtimes. It owns
their exact book representation, canonical publication, public-source ingestion,
workload identity and lifecycle seams. It has no exchange credentials or order
authority. Venue-specific subscription/snapshot behavior stays with each runtime.

`src/lib.rs` exposes `book`, `decimal`, `publisher`, `runtime` and `source`.
Canonical Protobuf types are generated by `build.rs` from the sibling schema
owner; common decimal types come from the workspace's compatibility library.
The Cargo package identity stays `kanz-market-feed` despite the source path.

From the repository root with the pinned Rust toolchain:

```sh
cargo +1.90.0 test --locked --manifest-path rust/Cargo.toml -p kanz-market-feed
```

Use the [Binance](../../services/binance_depth/README.md) and
[OKX](../../services/okx_depth/README.md) runbooks for configuration and real
transport qualification. A unit pass does not transfer feed ownership or
establish broker acceptance. See [the workspace guide](../../README.md) for
cross-language compatibility and source/deployment boundaries.
